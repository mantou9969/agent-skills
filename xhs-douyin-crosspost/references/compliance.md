# 搬运的边界：能做什么、不能做什么

## 能搬的

- 本人原创、本人拍摄/剪辑的成片，从自己的小红书/抖音同步到自己的 YouTube/Instagram。
- 本人有书面授权（合作方、客户、代运营）的内容，授权范围要覆盖"海外平台二次发布"。
- 自己账号的历史作品重新剪成竖版再发。

## 不能搬的

- 别人的笔记/视频。哪怕去水印、改速度、加字幕，也是侵权；YouTube 的 Content ID 和 Instagram 的版权投诉都会打到账号上。
- 素材库里当"参考"收藏的博主内容——那是用来抄选题和封面的，不是用来发的。
- 影视、综艺、动漫片段，平台曲库以外的音乐。
- 带第三方个人信息的内容：手机号、地址、订单号、聊天截图里的头像和昵称。

## 发之前必须过的手

1. **版权**：`rights.is_own_work = true` 只能由本人确认后写。
2. **隐私**：画面和文案里没有别人的姓名、电话、地址、订单号；聊天记录截图要打码。
3. **水印**：原平台的 logo、账号水印、二维码要处理掉，别把小红书水印端到 YouTube。
4. **音乐**：平台曲库能用的才用；不确定就换无音乐或平台自带音频。
5. **文案**：不写"最好的""第一""治愈百病"这类绝对化宣称；不编产地、材质、价格。
6. **标识**：YouTube 上传时如实回答"是否为合成/改编内容"；商业推广按平台要求标注。

## 账号风险

- 短时间大量重复上传会被判 spam；每天 3 条、内容各不相同才是安全节奏。
- 同一视频在两个平台的时间差不要紧，但别把同一文件反复改标题重发。
- Instagram Reels 对带其他平台水印的内容会降权。

## 数据留在本机

- 原片、成片、cookies、授权 token 都在 `%USERPROFILE%\crosspost`。
- cookies.txt 等同账号钥匙：不要提交到 git、不要贴进聊天、不要传云盘。
- 交接给别人时，先删 `secrets/` 和 `config.json` 里的 token。
