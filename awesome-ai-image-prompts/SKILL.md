# Awesome AI Image Prompts

Use the local prompt library only when inspiration or a concrete visual construct is needed. Do not paste the entire library into the conversation.

## Routing

- For product photography, read [references/awesome-ai-image-prompts.md](references/awesome-ai-image-prompts.md) and search for `Product Photography`, then inspect only relevant entries.
- For fashion, portraits, food, branding, architecture, or cinematic concepts, search the same reference for the matching section.
- Borrow structure such as subject, environment, lighting, camera, composition, palette, texture, and negative constraints.
- Replace names, brands, products, faces, and unsupported claims with facts from the current job.
- When the user provides a product photo, keep the actual product's shape, color, material, quantity, text, and logos fixed; the library is inspiration, not authority.
- Do not copy third-party images or attributed prompt text verbatim into a deliverable if the user asks for original work. Recombine the visual principles into a new prompt.
- Platform rules and commercial rights still require verification from the current platform and the original prompt author.

The upstream project and license are recorded in the source archive. If a prompt includes a named brand or recognizable person, treat it as an example only and do not create an unauthorized imitation.
