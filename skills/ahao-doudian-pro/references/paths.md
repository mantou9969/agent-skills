**猜你喜欢有两个入口，都真，别写成同一个：**
- **资格诊断页**：`抖店 → 商城运营 → 猜你喜欢准入`（看「入选诊断&优化建议」列，这才是结论）。
- **运营页**：`流量 → 流量运营 → 推荐卡运营`（v19 那帧的入选规则表在这里）。

**诊断结论门槛是「评价」不是「销量」**：新链接哪怕转化率 25%，`综合好评 0.00%` 一样进不去；197 单的老链接能入选是因为有真实评价累积。→ **起店第一周真正要买的不是流量，是第一批带文字的详评**（平台促评口径：每 10 条详评，商品销量 +15%、商城曝光 +3%）。

`价格助手` 这个菜单第一次拍到——比价/校验价大概率从这里管理，但他没点开，**没有画面证明，只当线索**。

## B. 开店后要做的设置（v55，逐条路径）

总纲一句：**抖音电商非搜索流量占 60%+，先铺货盘再深耕。**

| # | 事项 | 路径 | 要点 |
|---|---|---|---|
| 1 | 支付方式 | 店铺 → 店铺信息设置 → 店铺设置 → 支付方式设置 | 抖音支付默认已开通 |
| 2 | 绑定官方账号 | 店铺 → 经营账号管理 → 店铺官方账号 → 立即绑定 → 扫码 | **绑定后不支持解绑；只能分享本店商品；个人店官方账号必须非企业号** → 扫码前想清楚用哪个号 |
| 3 | 地址库 | 订单 → 物流工具 → 地址库管理 → 新增地址 | 退货地址填错会违规判罚 |
| 4 | 运费模板 | 订单 → 物流工具 → 运费模板 → 新建模板 | **唯一要改的是发货地改成合肥**；其余阶梯计价结构可照抄；限售地区可 Excel 批量导入 |
| 5 | 运费险 | 商家保障中心 → 保险服务中心 → 电商退换货运费险 → 立即开通 | 保费跟退货率挂钩（≤0.05% 时 0.01 元/单）；捏捏易碎基本必须开 |
| 6 | 售后小助手 | 售后 → 售后小助手 → 选择模板 → 创建策略 | 建「未发货自动同意退款」等，省人工 |
| 7 | 飞鸽客服 | 飞鸽客服工作台 → 自动化设置 → 自动接待 → 常见问题 | 最多 6 条，人工写 1 条其余智能补齐 |
| ★ | **开通抖音面单** | （v38 脑图列为独立一步，路径未拍到） | **代发最容易漏的一步**。平台原文（v55 新手锦囊）：`如需正常发货，请开通电子面单`。先后顺序没拍到，进后台自己确认 |

**体验分三条红线（v16 平台规则原文，阈值各不同，别混）：**
- 一个自然月内两次及以上 **低于 4.6 分** → 失去「好货商城」准入资格；
- 两次及以上 **低于 4.0 分** → 商品曝光权限被限制；
- 评分低于 4.0 或高于 4.6 → **无法报名平台活动**（分数是报活动的门票）。
分数掉下去基本没法主动救，只能靠这几个门槛在掉之前守住。

## C. 每日看数动线（照抄，5 分钟）

1. **抖店后台 → 首页 → 经营数据切「近1天」**：抄六项（成交金额、成交订单数、退款金额、曝光人数、点击人数、成交人数）+ 顶部「待发货/异常包裹/待处理违规」。
2. **核心数据-抖音电商 → 电商罗盘（经营）→ 近1天**：先看经营概况五项，再看右侧**退款率 / 投放费比 / 综合费比**，再看**载体分布**（判断商品卡 vs 短视频谁在出单）。
3. **抖店 → 商机中心 → 报名管理 → 商品行「数据详情」**：看单条链接的曝光/成交金额/成交订单**逐日曲线**（比首页大盘有用，AI 摘要从没提过这个入口）。
4. **巨量千川 → 乘方 → 计划视图**，日期先选昨天、再选今天，看流速掉没掉。

## D. 免费流量任务（v16，唯一必吃的扶持）

位置：抖店里的**「做任务赚流量」**。原「新品破10」已变更成两个板块：**「7天破4单爬坡扶持」**和**「15日破X出爆扶持」**。
- 列表只看：7天/15天内发布、且未完成过冲刺任务的店铺新品。
- 三种情况：列表没品→去提报店铺新品；有品显示任务→去完成任务；有品显示暂无任务→可发布新商品。
- 「暂无任务」原因：没有同款不可比价且冲刺剩余 <4 天；任务已过期（距发布 >7 天）。
- 排序：冲刺中新品按剩余天数从少到多，优先做最紧迫的。

**「7 天破 4 单」是唯一一定要吃到的**：4 单量级 3000 预算扛得住，是唯一不需要资质、不需要历史销量的免费流量，且**7 天后永久过期**。同一批订单同时解锁「新品流量扶持 + 猜你喜欢入选资格（历史有效成交 >0）」。

**但 4 单不是目标本身**——这 4 单要能回答三个问题（v13 红字原文：`不要只等商品卡自然流量`）：
1. 哪一种人群更容易成交；2. 哪一个使用场景更容易出单；3. 哪一条渠道更适合这个产品。
→ 每周数据表加三列：**谁买的（人群）/ 为什么买（场景）/ 从哪条渠道来（渠道）**。凑出来但三列全空的 4 单等于白跑。

**标题优化**（v16，免费）：词从**电商罗盘搜索词 + 抖音搜索下拉框**来（都免费，不用千川）。硬阈值：**关键信息放前 20 字内**。追热四槽位：节假日 / 行业热搜 / 产品热词 / 场景。

## E. 一件代发发货：抖掌柜（v34，对我们最实用的一集）

- **身份**：抖掌柜·抖店管理系统（douzhanggui.com），服务市场商品名「**抖掌柜一键下单**」。简介：`1688货源一键下单，采用1688官方接口支持密文全自动下单、自动售后、多店铺管理，物流同步、自动发货、利润统计`。
- **价格**：参考价格 **¥0**，试用版 7 天 **¥0**（免费试用）。5 项功能试用版和专业版都是 ✅（一键下单/密文下单/自动售后/电子面单自动发货/利润统计）→ **¥0 试用版就能测完全部功能，不用先付钱**。
- **装法**：服务市场搜「抖掌柜一键下单」，选试用版/7天。备选：智能店长、妙手、晓风上货（都标免费试用）。

**后台菜单（实机）**：
```
├ 账户：账户概览 / 数据大屏 / 店铺绑定 / 采购账号
├ 订单：一键下单(默认) / 自动下单 / 下单设置 / 货源关联
├ 售后：抖店售后 / 退货地址
├ 商品
└ 统计
```
每天盯的订单队列：`未采购待发货｜已采购待发货｜将逾期发货｜已逾期发货｜已发货｜需手动处理`。

**代发下单点击顺序**：
```
订单 › 一键下单 → 订单行右侧【手动采购】 → 弹出「采购下单」
（左=抖店订单信息，右=1688采购信息）→ 选规格 → 「－ 0 ＋」填数量
→ 选支付方式（先采后付/支付宝，默认先采后付）→ 橙色【代发下单】
```

**三条只有画面里才有的关键事实：**
1. 🔴 红色警示条 `供货商【XX】未绑定退货地址`——修复位置在左菜单 `售后 › 退货地址`。**不用问供应商**（10-28 实测：发短信给 1688 批发商问细节，没人回；批发商不为个人代发客户答疑）。解法：**退货地址直接填我们自己的合肥地址**，退回来的货自己收当拍摄道具/样品，第一单退货不会砸手里，还省了买样品的钱。
2. **成本价不是你填的，是直接读 1688 当时现价**——代发价会当场变（厂家从 96.5 涨到 105，你利润无提醒被吃掉）。→ 售价按「1688 现价 + 运费 + 佣金 + 运费险 + 退货损耗」留余量，不按今天报价定死。**也不要指望供应商提前告知调价**：改用两个自己控制的闸门 —— ① **计价用页面最高的那档**（君跃有「60天老客价 ¥3.8」就按 3.8 算，不按 1 件起批的 3.5）；② **每周自动核一次页面价**，涨过阈值（>4.5）就切同款备选货源（君跃页面自己列了 云绪¥0.63／佬巴¥1.80／创柴¥3.05／锡达¥3.3）。
3. **「先采后付」额度是 1688 侧的，等于厂家垫资**——缓解 3000 元本金 + 抖店 21 天回款的现金流压力，不用先掏钱进货。

利润就在这屏上：`抖店实收 − 1688 采购价 = 毛利`，列表里有「利润」列自动算。

**没拍到、不要假装知道**：抖店「开通/授权电子面单」页面、1688 网页本身、`下单设置`/`货源关联` 菜单内部、专业版报价。

## F. 商品卡诊断的曝光受限三查（v13，顺序不能颠倒）

**先查有没有曝光受限**（这三件没解决，后面改再多也没用）：
`猜你喜欢未入选`（有诊断页，见 A）/ `搜索限制曝光` / `价格力影响曝光`（**后两个至今没拍到实际页面**，别以为也有诊断页）。
没受限，再看卡在曝光、点击还是成交：**没人点不要先改详情**；有人点不买才看 SKU/评价/详情/到手价。

四种数据状态 → 动作：
| 状态 | 动哪里 |
|---|---|
| 有曝光、点击低 | 主图、价格，以及进来的人是不是你想卖的人 |
| 有人点击、成交差 | SKU、评价、详情、最终到手价 |
| 转化不错、流量很小 | 加已验证过的搜索/内容/达人/活动/付费 |
| 原来有流量、突然下滑 | 拆搜索/猜你喜欢/活动/付费四路，找哪一路掉了 |

## H. AI 智能发品（1688 图 → 抖店上架）· 2026-10-30 首次实跑通

入口：`fxg.jinritemai.com/ffa/g/create`（商品 → 发布商品 → 智能发品）。

**流程（实测）：** 上传资料（商品图片 / Excel表格 / 任意截图，三选一或全给）→「下一步，生成商品」→ 系统分类出「商品主图 / 商品详情」+ 推荐标题 → 商品类目若没推荐结果点「手动选择类目」（抽屉里**顶部搜索框输商品名**，回车后出「搜索关联度优先」的三级路径，点最后一级即选中）→「确认信息，继续生成」→ 进完整发品表单 → 补属性/价格库存 →「发布商品」→「商品提交成功，需审核通过后生效，审核周期 1–2 个工作日」。

**表单里必须自己盯的几处（AI 会瞎填）：**
- **生产企业名称**：AI 直接编了一个不存在的公司。每次发品必查、改成 1688 公司档案上的真名。
- **适用年龄**：AI 填「3周岁以上」→ 触发 3C 强制认证口径。1688 写 14岁以上就选 **14周岁以上**。
- **材质**：抖店枚举里**没有 TPR**（只有 软塑料/橡胶/硅胶/PVC/eva材质…），TPR 选「橡胶」。
- **品牌**：填 **无品牌**。挂别人的品牌 = 侵权，个人店扛不住。
- **AI 只给 5 个款式**（1688 实际 15 款）：官方提示「补充包装信息、价格库存表，AI 识别成功率提升 50%」→ **下次把件重尺 + 逐款价库存做成 CSV 一起传**。

**发品前就要定好的（改价会压历史最低价）：**
- 多档（单只/三只/六只）**分链接**，不在同一链接上改价。
- 🔴 **先锁营销活动托管的报名价，再授权任何 AI 开店托管**（AI 会自动报活动、自动改标题）。
- 主图视频缺 → 质量分 91（优秀）也能上架，但转化率 -0.5%，用 AI 内容运营图生视频补。

**上架后立刻能领的（双11 新商政策，2026-10-15→11-11）：** 上架≥1 个有库存商品 → 最高 850 元 + 专属新商体验分 + 运费险补贴（30天内100单、每单0.01元）。

**退货地址是硬前置**：左侧「售后 › 退货地址」，第一单退货前必须填好（填我们自己的地址，代发退回来的当拍摄道具）。⚠️ 直接敲 URL `/ffa/after-sale/refund-address`、`/ffa/shop/address` 都是空页，**只能从左侧菜单点进去**。
