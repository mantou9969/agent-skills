## A. 我们是谁（决定一半建议能不能用）

**个人店 + 一件代发 + 3000 元试错资金 + 单人 + 无库存 + 无精选联盟 + 抖店 21 天回款。**
阿豪的默认前提是企业/个体户店 + 自有或工厂货源 + 千川预算。给任何建议前先确认这三件事（店类型 / 是否代发 / 有无投放预算），它们决定这条建议是不是废话。

## D. 四条硬红线（违反就掉流量 / 亏本金）

1. **切莫大改、变动出单产品**（v66 注意事项第4条）。已起量的链接别直接改价——直接改价会同时动到点击、转化、购买人群、价格带竞争、系统反馈。**用优惠券/活动去测；要改只改没出单的 SKU。**
2. **连续、轻微地给系统信号，不要强刺激成交**（第3条）。这是「不要刷单」的机制版：刷出来的单不连续、不自然，过不了第二关。
3. **保本ROI 是出价原点，不是事后算的账**。定价每降一档保火线跳一大截；被大促压到成本以下时，投放 ROI 再高也救不回来。薄利代发 SKU 一律不报强制比价大促。
4. **低价款不要和主推款挂同一条链接**（会被系统按低价人群定型，主推拉不高）。9.9 引流单独立链接，或干脆把「拉点击」交给短视频内容而不靠价格。

**达人佣金红线**：走「找达人挂橱窗」时，佣金率填之前必须先跑保本ROI表——15% 提成能吃掉 84% 净利。

## E. 类目风险：脆皮捏捏落在最差的一档

阿豪自己的类目锐评里，**玩具/百货是最差档**：同质化严重、客单价低、利润基本没有。脆皮捏捏正落其中。
**唯一出路是他那句话：打细分场景。**

差异化三个检验标准（上市前看市场站位，上市后从场景/人群/表达切）：
1. **能不能拍成视频**——对捏捏是天然优势（脆皮声 ASMR）；
2. **能不能一句话说清**——「谁、什么场景、为什么要买你这个捏捏」；
3. **有没有避开主流卖点**——别卖「解压玩具」这个泛概念。

切入点「三差」（v17）：`规格差 / 人群差 / 价值感差`，边界是「不一定推翻重做，换规格/换人群/换场景」。
- 对捏捏最快的是**人群差**：现成人群标签写「考研党专用 / 加班党专用」比「宝妈专用」更贴 ASMR。
- 多链接用**组合差**（3只装/6只装/盲盒装），不能只换主图（`每条链接要有真实区别，不能只换主图，内容和价格要对得上`）。

做不起来的三个原因（自检）：① 产品卖得太泛（「解压玩具」就是泛）；② 没有任何一条成交路径做透；③ 千川只堆素材不做种草。

## F. 两个必须提醒的坑（引用这套方法时永远带着）

1. **他的前提不是你的前提**——只看诊断逻辑和定价算术，不看投放节奏。照抄他的千川节奏会死得很快。
2. **他是卖课的**——数据可信（有后台录屏、订单曲线），但「必须这么干」的语气要打折，他永远在强调技巧、不会说「这个类目别做」。
