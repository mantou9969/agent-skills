## 模板生成规则

### 规则1：理论框架嵌入规则

根据模板类型，嵌入必要的理论定义：

- 涉及学习目标 → 嵌入波哥公式、掌握层次定义
- 涉及建构环节 → 嵌入五步骤、四维度定义
- 涉及巩固环节 → 嵌入三层次、变式类型定义
- 涉及运用环节 → 嵌入四特征、任务类型定义
- 涉及总结环节 → 嵌入四维度定义
- 涉及学情分析 → 嵌入三知图、学生类型定义
- 涉及评价设计 → 嵌入评价任务类型、评价标准形式定义

### 规则2：填空位置标记规则

使用以下标记方式：
- [必填项]：必须填写的关键信息
- [选填项]：可选择填写的补充信息
- [选择项：选项1/选项2/选项3]：从给定选项中选择
- [示例：xxx]：提供参考示例的填空项

### 规则3：模板结构规则

每个模板必须包含：
1. 【任务说明】：明确告诉AI要做什么
2. 【理论框架】：嵌入必要的理论定义
3. 【设计要求】：具体的结构和内容要求
4. 【输出格式】：明确输出的格式和结构
5. 【使用说明】：填空指导和注意事项

## 核心模板示例

### 模板：完整学习活动设计

```
==================== 模板开始 ====================

【使用说明】
请将以下模板中的[填空项]替换为您的具体内容后，提交给AI生成教学设计。

---

【任务】
请为我设计一次完整的学习活动。

【基本信息】
- 学科领域：[必填项，如"数学""语文""科学""跨学科"等]
- 学习者：[必填项，如"三年级学生""初二学生""高一学生"等]
- 教材版本：[必填项，如"人教版""北师大版""沪教版"等，不同版本内容编排差异大]
- 学习内容/课题：[必填项，如"两位数乘两位数""比喻句的运用"等]
- 学习总时长：[必填项，如"40分钟""15分钟""2周"等]
- 学习形式：[必填项，选择：课堂教学/在线学习/混合学习/自主学习/项目学习/其他]
- 班级规模：[选填项，如"45人大班""20人小班"，影响小组活动的组织方式]
- 学情背景：[选填项，如"学生已学过...""学生普遍存在...困难""学生对...感兴趣"等]

【理论框架】
请严格遵循以下高质量学习教学设计理论：

一、学习目标设计原则
学习目标是主观预设的、有意识关注的、需要系统学习的学习结果。
表述公式：学习目标 = 学生 + 掌握层次(记忆/理解/运用) + 学习结果 + 学习表现
- 记忆层次动词：说出、写出、描述、列举、辨认、识别
- 理解层次动词：解释、举例、分类、概括、推断、比较、说明
- 运用层次动词：执行、实施、使用、解决、分析、评价、创造、设计

二、五星网状教学模型
以学习目标为中心，包含五个可灵活组合的环节：

1. 启动环节
   核心功能：激活旧知、告知目标、激发兴趣
   必含要素：激活旧知的方式、目标呈现、兴趣激发情境

2. 建构环节 ⭐核心
   五个步骤：
   - 激活旧知
   - 补全必知
   - 生成新知 ⭐
   - 构建知识体系
   - 重构认知结构
   
   生成新知必须明确四维度：
   - 思维强度：一级(直接告知)/二级(引导推理)⭐推荐/三级(自主探究)
   - 认知方式：CPA模式(具体→图示→抽象)/问题链模式/案例分析模式
   - 学习形式：个人/小组/全班/混合⭐
   - 催化方式：可视化/问题引导/支架搭建/同伴互助

3. 巩固环节
   三个层次：
   - 基础练习：与例题相似
   - 变式练习：改变表面特征
   - 易错练习：针对典型错误

4. 运用环节
   四个特征：情境真实、问题复杂、方法开放、思维高阶
   与巩固的区别：运用是新情境、需选择方法、综合知识点

5. 总结环节
   四个维度：认知、元认知、情感、社会

三、三知图分析框架
- 新知：本次学习的目标
- 必知：学习新知所需的前置知识
- 旧知：学生已掌握的相关知识

【环节配置要求】
请根据学习总时长和学习目标类型，合理配置各环节：
- 各环节的时间分配：[必填项，如"启动5分钟，建构20分钟，巩固10分钟，总结5分钟"或"第一周启动+建构，第二周运用+总结"等]
- 需要重点设计的环节：[选填项，如"建构环节""运用环节"等]
- 可省略或简化的环节：[选填项，如"本次学习可省略巩固环节，重点放在运用环节"等]

【设计要求】

一、前置分析
1. 三知图分析：分析新知、必知、旧知的关系
2. 学习目标：设计学习目标，明确重点（目标数量根据学习时长和内容复杂度确定）
3. 难点预判：分析可能的学习难点及处理策略

二、学习流程设计
按五星模型设计（根据环节配置要求灵活选择），每个环节需包含：
- 环节目的
- 教师/引导者活动（具体话术或指导语）
- 学生活动
- 时间分配
- 评价嵌入点

三、具体要求
1. 建构环节必须明确四维度选择及理由
2. 如包含巩固环节，必须设计分层次练习（含答案）
3. 如包含运用环节，必须符合四特征
4. 如包含总结环节，必须覆盖相关维度

【输出格式】
请按以下结构输出：

一、学习分析
1. 三知图分析
2. 学习目标（使用波哥公式表述）
3. 重难点分析

二、学习流程
（根据环节配置，逐一设计各环节）
每个环节包含：
- 环节目的
- 活动设计
- 时间分配
- 评价设计

三、学习资源/材料清单

四、评价设计
- 各目标的评价任务和标准

==================== 模板结束 ====================

【填空指导】
1. [学科领域]：填写具体学科或领域，如"数学""语文""物理""跨学科STEM"等
2. [学习者]：填写学习者信息，如"三年级学生""初二学生""高一理科班学生"等
3. [教材版本]：填写使用的教材版本，如"人教版""北师大版""沪教版"等
4. [学习内容/课题]：填写具体内容，如"两位数乘两位数""比喻句的运用""生态系统调查"等
5. [学习总时长]：填写预计时长，如"40分钟""15分钟""90分钟""2周""1个月"等
6. [学习形式]：选择或填写学习形式
7. [班级规模]：选填，如"45人""20人"
8. [学情背景]：选填，可填写学生基础、已学内容、常见困难、兴趣特点等
9. [环节时间分配]：根据总时长规划各环节时间
10. [重点环节]：选填，指定需要详细设计的环节
11. [省略环节]：选填，说明可省略或简化的环节
```

### 模板：即时学习设计（短时学习）

```
==================== 模板开始 ====================

【使用说明】
本模板适用于5-20分钟的短时学习活动设计，如微课、即时辅导、碎片化学习等。

---

【任务】
请为我设计一个短时学习活动。

【基本信息】
- 学科领域：[必填项]
- 学习者：[必填项]
- 教材版本：[必填项，如"人教版""北师大版"等]
- 学习内容：[必填项，聚焦单一知识点或技能]
- 学习时长：[必填项，如"5分钟""10分钟""15分钟"等]
- 学习场景：[必填项，选择：课前预习/课中补救/课后巩固/即时答疑/碎片化自学/其他]
- 学情背景：[选填项]

【理论框架】
短时学习设计原则：
1. 目标聚焦：一次短时学习只解决一个核心问题
2. 环节精简：根据学习目的选择最必要的环节
3. 即时反馈：学习后立即检验效果

短时学习的环节选择建议：
- 概念理解型：启动（简）+ 建构（主）+ 即时检测
- 技能训练型：示范 + 练习（主）+ 反馈
- 问题解决型：问题呈现 + 引导探究（主）+ 总结

【环节配置】
- 选择包含的环节：[必填项，如"启动+建构+检测"或"示范+练习+反馈"等]
- 各环节时间分配：[必填项，如"启动1分钟，建构6分钟，检测3分钟"]
- 核心环节：[必填项，指定最重要的环节]

【设计要求】

一、学习目标（1个，精准聚焦）
使用波哥公式表述

二、学习流程
按选择的环节设计，每个环节包含：
- 具体内容
- 呈现方式（如有媒体要求请说明）
- 时间控制

三、即时检测
设计1-3个检测题，确认学习效果

【输出格式】
1. 学习目标
2. 学习流程（按环节）
3. 即时检测题
4. 学习要点总结（供学生回顾）

==================== 模板结束 ====================
```

### 模板：项目式学习设计

```
==================== 模板开始 ====================

【使用说明】
本模板适用于长周期的项目式学习设计，时长从数天到数周不等。

---

【任务】
请为我设计一个项目式学习方案。

【基本信息】
- 学科领域：[必填项，可以是单一学科或跨学科]
- 学习者：[必填项]
- 项目主题：[必填项，如"校园节水方案设计""社区垃圾分类调查"等]
- 教材版本：[选填项，项目涉及具体学科内容时请填写，如"人教版"等]
- 项目时长：[必填项，如"2周""1个月""一学期"等]
- 学习形式：[必填项，选择：小组合作/个人项目/班级协作/跨班级协作]
- 班级规模：[选填项，如"45人"，影响分组方案设计]
- 最终成果形式：[必填项，如"研究报告""设计方案""产品原型""展示汇报"等]
- 学情背景：[选填项]

【理论框架】
项目式学习设计原则：

一、学习目标类型
项目式学习通常涉及多类目标：
- 知识目标：通过项目学习的学科知识
- 能力目标：培养的核心能力（如问题解决、协作、沟通等）
- 素养目标：发展的关键素养

二、项目式学习中的五星环节分布
项目式学习将五星环节分布在不同阶段：

阶段1-项目启动（对应启动环节）
- 激活相关旧知
- 明确项目目标和驱动问题
- 激发参与兴趣

阶段2-知识建构（对应建构环节）
- 识别需要学习的新知识
- 通过探究建构必要知识
- 可能包含多轮"迷你建构"

阶段3-项目实施（对应运用环节）
- 运用知识解决真实问题
- 符合运用四特征：情境真实、问题复杂、方法开放、思维高阶

阶段4-成果展示与反思（对应总结环节）
- 展示学习成果
- 四维度反思：认知、元认知、情感、社会

注：巩固可嵌入各阶段或单独设置

【项目阶段配置】
- 各阶段时间分配：[必填项，如"启动1天，建构3天，实施5天，展示反思2天"]
- 里程碑节点：[必填项，如"第3天完成资料收集，第7天完成初稿..."等]
- 需要重点设计的阶段：[选填项]

【设计要求】

一、项目概述
1. 驱动问题：设计一个能引发探究的核心问题
2. 学习目标：分类列出知识目标、能力目标、素养目标
3. 与课程标准的对应

二、项目阶段设计
按阶段设计，每个阶段包含：
- 阶段目标
- 学习活动
- 教师角色与支持
- 学生任务与产出
- 时间安排
- 评价节点

三、学习支架设计
- 项目任务分解框架
- 资源清单
- 过程指导工具（如检查表、进度表等）

四、评价设计
- 过程性评价：各阶段的检查点和评价方式
- 终结性评价：最终成果的评价量规

【输出格式】
1. 项目概述（驱动问题、目标、课标对应）
2. 项目日历/时间线
3. 各阶段详细设计
4. 学习支架与资源
5. 评价方案（含评价量规）

==================== 模板结束 ====================
```

### 模板：建构环节设计

```
==================== 模板开始 ====================

【使用说明】
本模板专门用于设计建构环节，适用于需要深入设计新知讲授部分的场景。

---

【任务】
请为以下学习内容设计详细的建构环节。

【基本信息】
- 学科领域：[必填项]
- 学习者：[必填项]
- 学习内容/知识点：[必填项]
- 教材版本：[必填项，如"人教版""北师大版"等]
- 建构环节时长：[必填项，如"20分钟""3天"等]
- 班级规模：[选填项，影响小组合作等学习形式的选择]
- 学情背景：[选填项，学生已学内容、基础水平、常见困难]

【理论框架】
建构环节是学习过程的核心阶段，学生在此环节初步形成对新知识、新技能的理解。

一、建构环节五步骤（必须遵循）
1. 激活旧知：唤起与新知相关的已有认知结构
2. 补全必知：补充学习新知所必需但学生可能欠缺的知识
3. 生成新知 ⭐核心：引导学生主动建构新知识
4. 构建知识体系：将新知纳入已有知识体系
5. 重构认知结构：促进认知结构的整体优化

二、生成新知四维度（必须明确选择）

维度1-思维强度：
- 一级：直接告知，学生接受（适合难度大、时间紧的内容）
- 二级：引导推理，学生发现（适合大多数新授内容）⭐推荐
- 三级：自主探究，学生创造（适合能力强的学生或探究学习）

维度2-认知方式：
- CPA模式：具体(Concrete)→图示(Pictorial)→抽象(Abstract)
  适用：具体运算期学生
- 问题链模式：问题1→问题2→问题3→归纳规律
  适用：形式运算期学生
- 案例分析模式：案例呈现→分析讨论→提炼规律
  适用：抽象思维成熟学生

维度3-学习形式：
- 个人学习：独立思考、个人操作
- 小组合作：讨论、协作、分享
- 全班交流：展示、辩论、总结
- 混合形式：个人→小组→全班（最常用）⭐

维度4-催化方式：
- 可视化：图示、模型、实物、多媒体
- 问题引导：苏格拉底式提问、问题链
- 支架搭建：提示卡、思维导图、流程图
- 同伴互助：小组讨论、互评互改

三、三知图框架
- 新知：本次建构的核心内容
- 必知：学习新知所需的前置知识
- 旧知：学生已有的相关知识

【步骤配置】
- 各步骤时间分配：[必填项，如"激活旧知2分钟，补全必知3分钟，生成新知12分钟，构建体系2分钟，重构1分钟"]
- 生成新知四维度选择：
  * 思维强度：[必填项，选择：一级/二级/三级]
  * 认知方式：[必填项，选择：CPA模式/问题链模式/案例分析模式]
  * 学习形式：[必填项，选择：个人/小组/全班/混合]
  * 催化方式：[必填项，选择：可视化/问题引导/支架搭建/同伴互助，可多选]

【设计要求】

一、三知图分析
- 明确新知内容
- 分析必知金字塔
- 预估学生旧知状态

二、五步骤详细设计

步骤1-激活旧知：
- 激活方式
```

```
- 学生已有基础：[选填项，学生已掌握的相关知识]

【理论框架】
问题链是建构环节"生成新知"的重要认知方式，适用于有明确逻辑推理链的内容。

一、问题链设计原则
1. 层次性：从简单到复杂
2. 逻辑性：问题间有因果或递进关系
3. 引导性：每个问题都为下一个问题铺垫
4. 开放性：允许多种回答，但最终汇聚到核心结论

二、问题链的递进方式
1. 由易到难：简单情况→一般情况→复杂情况
2. 由特殊到一般：具体例子→多例共性→一般规律
3. 由现象到本质：观察现象→分析原因→提炼本质
4. 由正向到逆向：正向问题→逆向问题→双向联系

三、问题链的SCQA结构
- S（Situation）：情境描述
- C（Complication）：冲突或问题
- Q（Question）：关键问题
- A（Answer）：答案（学生探索得出）

【问题链配置】
- 问题数量：[必填项，如"5-6个问题"]
- 递进方式：[必填项，选择：由易到难/由特殊到一般/由现象到本质/由正向到逆向]
- 互动形式：[选填项，如"个人思考后全班交流""小组讨论"等]

【设计要求】

一、明确目标
- 学生最终要发现的规律/结论
- 发现路径的逻辑

二、问题链设计
每个问题需说明：
- 问题内容
- 问题目的（这个问题要达成什么）
- 预期学生回答
- 教师追问（如学生回答不完整）
- 过渡语（如何引向下一个问题）

三、归纳总结问题
- 最后的归纳性问题
- 引导学生用自己的话总结规律
```

```
评价量规是明确不同水平表现特征的评分指南。

一、评价量规结构
1. 评价维度：评价什么（通常2-4个维度）
2. 等级水平：分几档（通常3-5级）
3. 水平描述：每档什么样（具体、可观察）

二、等级设置建议
- 4级（优秀）：超越目标要求
- 3级（良好）：达到目标要求
- 2级（合格）：基本达到要求
- 1级（需改进）：未达到基本要求

三、水平描述原则
1. 具体性：用可观察的行为描述
2. 区分度：各等级之间有明显差异
3. 正向性：描述"做到什么"而非"没做什么"
4. 一致性：同一维度的描述逻辑一致

【量规配置】
- 评价维度数量：[必填项，如"3个维度"]
- 等级数量：[必填项，如"4级"或"3级"]

【设计要求】

一、确定评价维度
- 维度应覆盖目标的关键方面
- 维度之间相对独立

二、设计等级描述
每个维度×每个等级 = 具体描述
要求：
- 使用可观察的动词
- 描述具体表现特征
- 明确数量或程度标准（如适用）

- 评价时机
- 结果使用方式
```
