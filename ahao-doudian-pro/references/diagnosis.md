## A. 商品卡起量的四大关卡（v66，按顺序过，不能乱）

定义：**起量 ≠ 起订单 ≠ 起GMV ≠ 起ROI**。底层逻辑是「系统对商品进行验证，判断是否值得继续给你流量」。判据不是今天几单，是系统有没有把这一页翻过去。

| 关 | 判据（他要看的） | 核心是 | 核心影响因素 |
|---|---|---|---|
| 第一：点击是否成立 | 点击量稳定、人群稳定 | 商品推给对的人 | **标题、首图** |
| 第二：成交情况 | 成交是不是自然发生的？有没有连续性？ | 是不是有推广价值的产品 | **价格、详情页、主图视频、评价** |
| 第三：店铺情况 | 体验分稳定 | 流量承接得住 | **评价、物流、客服** |
| 第四：能不能放量 | 市场热度、产品热度、放量途径、坑产水平 | 市场反应、商品内容 | （无） |

- **前三关没过就谈放量 = 白花钱。**
- **坑产机制**（v64）：`成交形成坑产` → `坑产稳定后，平台才会继续推荐`。坑产不稳就别想放量。
- **缺口**：v66 原 PPT 共 7 页，视频只播到第 5 页；第 6 页标题「产品力」正文糊掉，第 7 页没露。引用时不要假装讲完了。

### 起量注意事项五条（v66 逐字）
```
1、心态稳，接受正常波动，不能心急，注重长期目标
2、看数据
3、连续、轻微地给系统信号，不要强刺激成交
4、切莫大改、变动出单产品
5、增加放量渠道（口播：不能在一个渠道上吊死）
```
三条直接约束动作：
- **第 4 条** → 能不改价就不改，要改只改没出单的 SKU（见 pricing.md 改价约束）。
- **第 3 条** → 是「不要刷单」的机制版：刷出来的单不连续、不自然，过不了第二关。
- **第 5 条** → 我们现在只有抖音一条线，小红书线算第二个渠道，不是竞争关系。

## B. 千川四指标诊断树（v65）

总纲：**`ROI只是结果，重点看消耗、曝光、千展、点击`**。ROI 用来定出价，四个过程指标用来找病。

**诊断顺序定死：曝光 → 千展 → 点击 → 成交。曝光低就别改素材。**

| 指标 | 定义 | 判读 |
|---|---|---|
| 消耗 | 商品和素材有没有足够的成交信号 | 基础弱 + 素材没讲出购买理由 → 消耗慢。影响因素四个：**店铺、链接、目标roi、视频** |
| 曝光 | 商品拿到多少展示机会 | 曝光高→往下看点击和成交；曝光低→流量入口没打开；**曝光高但点击低→问题在素材**；**曝光高但成交低→问题在商品页/价格/评价** |
| 千展 | 一千次曝光要花多少钱（= ECPM 的另一种叫法） | 千展高=买流量贵（类目竞争大 或 素材不够吸引）；千展高×投产正=贵但值；千展高×投产不正=流量没被接住→改素材/卖点/价格/详情页；**千展低×投产正=好信号，有放量机会** |
| 点击 | 用户看见后愿不愿点进来 | 点击高≠能成交，还要看价格/详情页/评价/优惠能不能承接；点击高但成交低→素材把人吸进来但商品页接不住 或 承诺太强不符预期；点击低=视频不够打动人→**优先改卖点、价格钩子和利益点** |

**放量唯一信号：千展低 + 投产为正。其他情况一律不放。**

## C. 掉量排查链（v65 实战第①问，分两支）

```
链接和店铺：查库存、价格和优惠、评价 / 店铺违规
计划：消耗和点击下降 → 素材衰退 → 补新素材，换开头、换卖点
      成交和 ROI 下降 → 查库存、价格和优惠、评价
      千展变高 → 同行竞争变强
```
**顺序：先查库存和违规，再查素材。** 别一掉量就动出价。

素材侧可执行三步（v63 §5.10-F）：
1. 查主力素材本身的点击率/完播率/GPM；
2. 拆（同行爆款 + 自己的主力素材），拆到「封面 / 开头 / 产品展示」三层；
3. 换方向做新素材（含跨行业爆款结构），迭代。

> 「跑不动」和「掉量」查的不是同一个东西：出价跑不动查的是「产品热度/类目热度有没有流量池 → 链接权重 → 素材 → 带货抖音号」。

## D. 新链接怎么投（v65 实战第②问）

```
切记不要放量。在有基础销量、评价后，上传多条素材进行赛马，对优质素材进行追投度过冷启动
```
**度冷启动靠「素材赛马 + 追投」，不是按一键起量，更不是放量。**

## E. 新素材不消耗（v65 实战第③问）

```
第一，不要只换皮——只换背景/音乐/字幕，卖点、开头、表达方式没变，系统眼里差异不大。
第二，要换角度——同一商品测不同角度：低价 / 场景 / 痛点 / 对比 / 使用前后变化。
第三，追投激活流量。
```
**「五个角度」= 第一批 5 条脚本选题**（能直接抄进内容清单）。
新素材合格线：**卖点/开头/表达方式必须变**，换皮不算新素材。

## F. 停掉追投就没消耗（v65 实战第④问）

```
第一，素材成交力不够——追投有量是钱包推的，一停系统觉得竞争力不够。
第二，商品基础不够强——价格/评价/详情页/SKU/优惠没让系统看到稳定成交可能。
第三，计划还没形成稳定模型——只靠预算冲了一波，没沉淀出稳定点击和成交信号。
```

| 症状 | 处方 |
|---|---|
| 没曝光 | 优化标题关键词；报活动 |
| 有曝光没点击 | 标题、主图、价格、销量数 |
| 有点击没转化 | 价格、销量、主图+视频+详情页、活动 |

## H. 标品 vs 非标品（决定主战场）

- **标品**（长得都一样：纸巾、数据线）→ 主战场是**搜索**。要标题、主图、坑产、价格、销量、品牌、差异化。
- **非标品**（款式多、看图决定买不买）→ 主战场是**猜你喜欢**。要点击率、成交、价格、评价、详情页、链接权重、体验分。
- **脆皮捏捏是非标品** → 指标是**点击率 / 转化率 / GPM**，不是搜索排名。

商品卡流量三块拼成：**搜索 35% + 推荐 40% + 活动 25%**。
搜索四权重：标题关键词匹配度 40% / 点击率 30% / 转化率 20% / 销量递增率 10%。
推荐看 **GPM = 点击率 × 转化率 × 客单价**（客单价太低的引流款在这个公式里天然吃亏）。

## I. 全域投不起来的 4 条件（v40，判断「够不够格投」）

按优先级：`视频/图片齐全` → `销量` → `评价` → `体验分`。
我们条件1能满足（素材是强项），条件2/3/4全没有 → **现在投全域就是浪费**。
3 个技巧（不花钱能做的）：平台活动 + 单品直降、优惠券。（第3个「高roi目标一键起量」要花钱。）
