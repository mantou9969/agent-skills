## A. 保本ROI —— 全手册最值钱的一句算术

**`保本ROI = 销售额预估 ÷ 净利润`**（他表格公式栏原文 `=G7/G14`）

含义：**千川投产比至少要跑到多少，广告费才刚好把净利润吃光。**
推导：广告消耗 = 销售额 ÷ ROI → ROI = 销售额 ÷ 消耗；令消耗 = 净利润，即得。
**跑得比它高 = 还赚钱；跑得比它低 = 直接亏本金。**

### 9 个紫底输入项（其余全是公式，勿动）
```
销售价 | 成本 | 发货前退款率 | 发货后退货率 | 签收率 | 快递费 | 运费险/损耗 | 主播提成 | 平台扣点
```

### 公式链（已被两组独立数据反推验证）
| 格子 | 算法 |
|---|---|
| 销售额预估 | 销售价 × 销售件数（**不扣发货前退款**，所以保本ROI 是偏乐观口径） |
| 签收率 | 1 − 发货前退款率 − 发货后退货率（不是手填经验值，是减出来的） |
| 总销售货值 | 成本 × 件数 × 签收率 |
| 签收销售额 | 销售额预估 × 签收率 |
| 快递费/运费险小计 | 单件费 × 件数 × (1 − 发货前退款率)（**发货前退款那几单运费照付**，代发最易漏） |
| 主播提成/平台扣点 | 签收销售额 × 比例 |
| 净利润 | 签收销售额 − 货值 − 快递 − 损耗 − 提成 − 扣点 |

### 关键结论
- **定价每降一档，保火线往上跳一大截**：他 29.9 档保本ROI = 3.571；同货降到 25，跳到 5.557（降 16% 售价，保火线涨 56%）。
- **客单越低，保本ROI 越夸张**：8.9 的货保本ROI = 6.189 → **低价链接靠千川投不动，只能靠自然流。**
- **达人佣金先跑这张表再填**：同一模板提点填过 2%（自播）和 15%（达人带货）；15% 那例吃掉净利的 84%。

## B. 打品定价公式（v17，8 个成本项）

```
定价 = 成本 + 渠道 + 利润
成本项：产品 / 包装 / 快递 / 售后 / 退货
渠道项：佣金 · 投放 · 活动
```
「渠道成本」明确含佣金、投放、活动三项。算代发价这 8 项都要摊。

**落地成本倍率**（v60 SKU 表反推）：`上架价格 ≈ 落地成本 × 2.1~2.2`。
→ **代发做 2 倍以上定价，才有可能在毛利上活下来。**

## C. 出价 = 保本ROI × 倍数（v63 脑图，全系列第一次给公式）

```
前期 → 跑放量投放，素材从主页上传；前期亏本正常，系统帮你探索人群
       → 出价 = 保本roi 去测试
中期 → 系统推荐保本roi 的基础上 ×1.2
后期 → 保本roi 的基础上 ×1.2 / 1.4 / 1.6
```
- **按真实成本 6.3 元重算后的出价原点**：29.9 主推档保本ROI = **1.626**，×1.2 = **中期目标 1.95**；19.9 点击款 1.928×1.2 = **2.31**；59.9 六只装 2.385×1.2 = **2.86**。
  ⚠️ 注意方向：**成本越低，保本ROI 越小、出价目标越松**。1.95 这种目标在千川很可能"跑得出量但不赚钱"，所以低保本ROI **不等于可以放松出价**，它是利润空间的证据，不是投放上限。**拿 9.9 档去投是反例**：4.411×1.2 = 5.29，常态跑不出 → 只能自然流。
- **上架前先定「出价原点」**：CSV 跑出的数 ×1.2 = 中期目标；**低于 4 才考虑投**。

### ECPM（抢流量的底层排序，v63/v50）
**`ECPM = 出价 × 预估点击率 × 预估转化率 × 1000`**
出价只能动第一因子，点击率和转化率由素材决定 → 同样出 3 块，CTR 5% 的素材比 CTR 2% 的 ECPM 高 1.5 倍。**这就是为什么他整集讲素材而不是讲出价。**

### 三条计划运维硬规则（v51/v63 逐字重复，可信）
```
及时关停废计划 → 连续 3 天消耗 < 预算 30% 且无转化的计划，直接删除重建
预算分配原则   → 单计划预算不超过账户总预算的 30%
出价调整频率   → 每天出价调整不超过 2 次，每次幅度 ≤10%，避免系统模型混乱
```
全域推广的 ROI 目标**不是想填多少填多少**：系统按商品给硬建议上限（他那条是 1.52，写明「过高可能影响获取流量」）。截图前先确认页面顶部是「放量投放」还是「控成本投放」——两套填法。

## D. SKU 三层结构（v35）

| SKU 层 | 职能 |
|---|---|
| 引流款 | 拉点击、**不做主力**、适合低预算用户 |
| 主推款 | 跑成交、价格适中、利润健康、重点承接内容 |
| 升级款 | 拉客单、提利润 |

价格阶梯：引流 < 主推 < 升级。**全片没出现任何具体价格数字**（9.9/19.9 是我们自己定的）。

🔴 **低价款带偏（他明确写的风险）**：
1. `链接方向被系统低估`——系统按引流的低价人群定型，之后推不动高价人群；
2. `主推款难拉高`。
→ **不要把 9.9 引流 SKU 和主推挂在同一条链接。** 两种改法二选一：
① 9.9 单独立一条链接（配合「一品多链接」，但必须「有真实区别」，不能只换主图）；
② 主推链接最低档就是 19.9，「拉点击」交给短视频内容，不靠价格。**建议先用 ②**（9.9 摊完 8 项成本毛利基本为零）。

**组合 SKU 才是利润主体**（他单品连上架价都没填）。SKU 名 = 规格 + 品名 +【里面到底有什么】+ 赠品，编码用自解释串（如 `24炉-24锅-无盖-赠20蜡`）——**名字自解释是防退款的**（对应「选错SKU」退款）。

## E. 活动比价卡控 —— 代发的头号杀手（v58/v59/v60）

### 大促「比价卡价」机制
报名成功后系统逐个 SKU 拿全网比价，算「校验价」往下卡。规则条原文四条：
```
报名价仅可偏低
提报全部sku
报名生效时间：仅大促活动期生效，日常不生效
审核时间：2天内审核
```
硬约束原文：**`此活动需商品下所有SKU参与活动，如存在SKU未参与活动，需在商品中心删除该SKU，方可报名。`**

**杀招 = 「报名价仅可偏低」+「提报全部sku」**：大促把价砍下去后**日常不生效但报名价回不去**，不能只退被卡的 SKU（要退整条链接，或去商品中心删 SKU）。校验价可低到售价 **5 折**（19.9→9.9）。退出活动**库存不回滚**。

### 官方后门（只在画面里，AI 摘要从没提）
- 已报名页右上角：`无需改价自动报名 ▸ 设置`
- 顶部：`营销活动托管…指定报名价托管，严防错价`
→ **报名前可以自己锁死报名价，或交给托管。** 不主动锁价，`营销活动托管` 会自动把商品报进混资。

### 对我们三条硬性修改
1. **代发薄利 SKU 一律不报强制比价的大促**（3000 本金被砍 8 元 = 砍掉一半毛利，且涨不回去）。
2. 一定要报 → 先设 `无需改价自动报名` 或走 `营销活动托管-指定报名价` 锁价，再提交。
3. 定价预留比价空间：售价按「代发价 + 运费 + 佣金 + 运费险 + 退货损耗 + 可能被砍的 10~15 元」定。**要么主推定到 39.9，要么不做套餐 SKU，要么彻底不碰「长周期大促」这种全年比价型活动**，只做单品直降 + 优惠券（自己定价，无校验价）。
4. 倒推公式：**打算报大促的最高档售价 ≥ 能接受的最低价 × 2。**

### 改价 48 小时闭环（v60，平台会发通知逼你改）
通知原文：`您参与的活动【混资货品补贴-长周期】…已不具备竞争力，请在48小时内调整价格，否则有被清退的风险。`
动线：`抖店 → 通知中心 → 快速处理模式 → 左侧「重要」→ 消息卡「活动商品改价提醒」→ 商品待办 →「去改价」→ 手动改价抽屉 → 逐 SKU 填数 →「同意改价」`。
平台还留了「申诉」这条路（不只「改价 or 退出」两条）。

### 改价为什么掉流量（v62 方法论）
直接改价会同时动到：点击、转化、购买人群、价格带竞争、系统反馈。
→ **不要在跑起来的链接上直接改价，用优惠券 / 活动去测。** 配合 v66 注意事项第 4 条「切莫大改出单产品」。

### 混资活动个人店报不了（v25）
资质原文：`至少满足其中之一：个体工商户店、企业资质店`，另要 `非新手期` + `体验分 ≥70`。
报名页原文卡点：`非新手村 / 个人店商家，商品近 30 日销量 ≥1`。
→ 办个体户执照能解锁第一条，后两条要先把店跑起来。**现阶段直接跳过，别浪费时间。**
