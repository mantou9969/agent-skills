## 核心心智模型（三句话）

- **起量 ≠ 卖得多。** 底层是「系统在验证这个商品值不值得继续给流量」。判据不是今天几单，是系统有没有把这一页翻过去。
- **ROI 只是结果。** 找病要看四个过程指标：**曝光 → 千展 → 点击 → 成交**，前一层不成立就别查后一层。
- **别用预算硬顶，用内容换信号。** 我们唯一擅长的路径是短视频自然流；他靠钱解决的地方，我们靠素材解决。

## 五大工作流（按需展开对应 reference）

### 1. 上架前：定价 + SKU 分层
先算后上架。填全链路成本 → 算 **保本ROI** → 定出价原点 → 决定这个价能不能投。
SKU 分三层（引流/主推/升级），**低价款不要和主推款挂在同一条链接**（会被系统按低价人群定型，带偏方向）。
→ 公式、9 个成本输入项、SKU 三层职能、定价硬线：`references/pricing.md`

### 2. 上架后：起量四大关卡诊断
按顺序过四关，**前三关没过就谈放量 = 白花钱**：
点击是否成立 → 成交情况 → 店铺情况 → 能不能放量。
→ 逐关判据、核心影响因素、坑产机制：`references/diagnosis.md`

### 3. 千川：四指标诊断树 + 掉量排查
消耗/曝光/千展/点击四指标，**放量信号只有一条：千展低 + 投产为正**。
掉量先查「链接和店铺（库存/价格优惠/评价/违规）」再查素材，别一上来就改出价。
新链接铁律：**不放量**，先攒基础销量+评价 → 多条素材赛马 → 给优质素材追投过冷启动。
→ 四指标逐字判读、掉量链、新素材合格线、五个测试角度：`references/diagnosis.md`

### 4. 活动报名：比价卡控是代发的头号杀手
大促「报名价仅可偏低 + 提报全部SKU」，校验价可低到售价 5 折，**日常不生效但报名价回不去**，退出还不回滚库存。
薄利代发 SKU **一律不报强制比价的大促**；只做单品直降 + 优惠券（自己定价，无校验价）。
混资活动个人店报不了（需个体户/企业店 + 非新手期 + 体验分≥70）。
→ 卡控机制原文、改价 48 小时闭环、活动闸门：`references/pricing.md`

### 5. 每日巡检 + 一件代发发货
每天 5 分钟照抄他的看数动线；免费流量任务「7 天破 4 单」是唯一必吃的扶持（7 天后永久过期）。
代发用**抖掌柜**（服务市场，有 ¥0 试用版）跑电子面单 + 自动拍单。
→ 后台路径、巡检动线、免费流量任务、抖掌柜：`references/paths.md`

## 硬红线（违反就掉流量 / 亏本金）

1. **切莫大改、变动出单产品**——已起量的链接别直接改价，用优惠券/活动去测；要改只改没出单的 SKU。
2. **连续、轻微地给系统信号，不要强刺激成交**——刷单过不了「成交是否自然、有没有连续性」这一关。
3. **保本ROI 是出价原点**——定价每降一档，保火线跳一大截；被大促压到成本以下时，投放 ROI 再高也救不回来。
4. **达人佣金先跑保本ROI表再填**——达人带货提成 15% 能吃掉 84% 净利，别拍脑袋给高佣。

→ 完整红线 + 能做/不能做两张表：`references/redlines.md`
